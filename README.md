# Explore India 

**A Travel Discovery & Booking Enquiry Management System**

## About the Project

Explore India is a full-stack web application that helps users discover Indian tourist destinations, explore travel packages and submit booking enquiries.

An admin can securely log in, view submitted enquiries and update their status.

This project is developed as part of a college web development project.

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Git and GitHub

## Main Features

- Explore tourist destinations.
- Browse travel packages.
- Search and filter destinations/packages.
- Submit travel enquiries.
- Admin authentication.
- Admin dashboard to manage enquiries.
- Update enquiry status.

## Project Structure

- `public/` — HTML, CSS, JavaScript and images.
- `routes/` — Express API routes.
- `server.js` — Main Express server.
- `database.js` — Database connection and queries.
- `init-db.js` — Database initialization.
